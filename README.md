# Sales Summary App

## Summary
This is a simple single-page application that fetches sales data from a CSV file and displays the total sales on the page.

## Setup
1. Clone the repository or download the files.
2. Open `index.html` in a web browser.

## Usage
The application will automatically fetch the `data.csv` file, calculate the total sales, and display it on the page.

## Code Explanation
- The HTML file includes Bootstrap 5 for styling.
- A fetch request retrieves the `data.csv` file.
- The sales values are summed and displayed in the `#total-sales` div.
